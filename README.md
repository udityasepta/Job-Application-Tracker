# Job-Application-Tracker

A responsive **Job Application Tracker** built using **HTML, CSS, and JavaScript**.

The project helps users manage job applications, track application status, search and filter applications, and save their data in the browser.

## 🚀 Features

* Add job applications
* Edit applications
* Delete applications
* Search by company or job role
* Filter applications by status
* Sort applications by newest or oldest
* Dashboard statistics
* Application status badges
* Dark / Light mode
* LocalStorage persistence
* Form validation
* Job URL support
* Responsive design

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript ES6+
* DOM Manipulation
* LocalStorage
* Responsive Web Design

## 📊 Application Status

The tracker supports four statuses:

* Applied
* Interview
* Selected
* Rejected

## ▶️ How to Run

1. Download or clone the project.
2. Open the project folder.
3. Open `index.html` in your browser.

No backend or installation is required.

## 💾 LocalStorage

The project uses the browser's `localStorage` to save job applications.

Therefore, applications remain available after refreshing the page.
